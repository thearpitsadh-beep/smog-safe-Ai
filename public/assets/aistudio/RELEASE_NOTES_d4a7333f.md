# SmogSafe AI 1.0.0

Features: family profile, labeled AQI source, hourly modeled forecast, daily plan, indoor air guide, commute impact calculator, secure Gemini server integration with rule fallback, location search and optional geolocation, downloadable plan, responsive UI.

Verification: syntax checks, Node unit/integration tests and offline desktop/mobile browser smoke tests.

Known limitation: live external-provider connectivity and paid Gemini calls need testing from your own internet-enabled deployment. The offline preview is explicitly demo-only.
